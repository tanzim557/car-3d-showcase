An immersive, interactive 3D car visualizer and customizer application delivering real-time WebGL rendering, camera orbital controls, custom materials, and smooth frame-sequence animations.

---

## Key Features

- Full 360 Degree Orbit and Camera Controls: Smooth camera panning, zooming, and orbital rotation powered by Three.js and React Three Fiber.
- Dynamic Material and Color Customizer: Real-time vehicle paint, metallic finish, and trim color toggling with realistic reflections.
- Cinematic Animations: Synchronized camera transitions, camera fly-throughs, and visual effects using GSAP.
- High-Fidelity Sequence Engine: Integrated frame-by-frame rendering and high-resolution video thumbnail showcases.
- Fully Responsive Experience: Glassmorphic UI overlays with responsive mobile and desktop viewports.

---

## Tech Stack

- Framework: Next.js (App Router, TypeScript)
- 3D Graphics and Canvas: Three.js, @react-three/fiber, @react-three/drei
- Animation: GSAP (GreenSock)
- Styling: Tailwind CSS, PostCSS
- Icons and UI: Lucide Icons, clsx, tailwind-merge

## Getting Started

### Prerequisites
- Node.js (v18.0 or higher)
- npm or yarn

### Installation
```bash
# Clone repository
git clone https://github.com/tanzim557/car-3d-showcase.git
cd car-3d-showcase

# Install dependencies
npm install

# Run development server
npm run dev
```

Open http://localhost:3000 with your browser to experience the 3D car showcase.

### Production Build
```bash
npm run build
npm run start
```
